## 👩🏻‍💻 Sobre mim

Olá! Sou **Júlia Brasileiro Viana**, estudante de Análise e Desenvolvimento de Sistemas e desenvolvedora Front-End em formação.

Tenho interesse em desenvolvimento de interfaces, experiência do usuário e criação de soluções digitais que realmente tenham utilidade.

Atualmente, meu foco está no desenvolvimento Front-End, enquanto amplio meus conhecimentos em Back-End, banco de dados e integração de sistemas.

Gosto de transformar ideias em projetos, experimentar novas tecnologias e aprender na prática. Acredito que cada projeto é uma oportunidade de evoluir tecnicamente e desenvolver uma visão mais completa sobre tecnologia.

**O que estou construindo:**
- Interfaces modernas, funcionais e responsivas.
- Aplicações web com foco na experiência do usuário.
- Projetos que integram diferentes tecnologias.
- Conhecimentos em desenvolvimento Back-End e banco de dados.
